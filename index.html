PlaidConnect

Link a bank account to your PlaidConnect server.

Where your PlaidConnect server is running. Update this to the LAN IP of the machine running the server (e.g. 192.168.1.x).
Must match the API_KEY env var on the server.
Hold Ctrl/Cmd to select multiple.
Setup notes

CORS: Your server allows any origin by default (CORS_ORIGIN=*). Serve this file so it's reachable on your LAN:

npx serve -p 5173 -l tcp://0.0.0.0:5173

Or with Python:

python3 -m http.server 5173

Then open http://192.168.1.170:5173 from any device on the network.
